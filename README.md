# Exercise Tracker

A full-stack Exercise Tracker application built with **React**, **Node.js**, **Express.js**, and **MongoDB**.

The project allows you to create users, add exercises, and view exercise logs with optional filters.

## Features

- Create a new user
- View all users
- Add exercises to a user
- View exercise logs
- Filter exercise logs by:
  - From date
  - To date
  - Limit
- Display exercise details in a simple UI
- View API responses as JSON
- Loading and error states
- Responsive interface

## Tech Stack

### Frontend

- React
- JavaScript
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
